Privacy Policy

Sunday Palette Live Automation · Effective November 1, 2026

This policy describes how the owner-operated Sunday Palette Live Automation tool accesses and uses Google account and YouTube data. The tool is intended for the channel owner's personal use, not public registration.

1. Data accessed

With the channel owner's consent, the application uses the YouTube Data API and the https://www.googleapis.com/auth/youtube.force-ssl OAuth scope. This is a YouTube management permission. The automation accesses relevant channel identity, live broadcast and live stream identifiers, titles, scheduled times, statuses, and broadcast-stream bindings as needed for its functions.

2. Purpose of use

Data is used to check the owner's current live session, create and schedule upcoming sessions, attach the appropriate stream, coordinate handoffs and check whether completed sessions are archived. It is not used for advertising, profiling or unrelated purposes.

3. Storage and security

OAuth credentials and access/refresh tokens are stored only in the channel owner's local authorization environment and access-controlled Oracle Cloud server configuration. They are not embedded in this public website or its GitHub repository. Operational records may include broadcast IDs, schedule times and status checkpoints. Only the owner manages this private infrastructure.

4. Sharing and disclosure

Google account and YouTube authorization data is not sold, rented or shared with advertisers or other creators. Necessary API requests are sent to Google/YouTube to perform the owner's requested automation. The public website is hosted on GitHub Pages; its hosting provider may process basic visitor request information under its own terms and privacy policy.

5. Data retention and control

Authorization data is retained only while needed to operate the owner's automation, unless earlier deleted by the owner. The owner can stop the automation, remove locally stored tokens and revoke the app's Google account access at any time via Google Account connections. Revocation prevents further authorized YouTube API operations until access is granted again.

6. Website visitors

This static website has no sign-in, account creation, input forms, advertising pixels, analytics scripts or cookies set by its own code. It does not request visitors' Google or YouTube credentials.

7. Contact

For questions about this owner-operated application or this policy, contact the application's support address displayed on its Google OAuth consent screen. Please never include passwords, tokens or stream keys in messages.

8. Updates

This notice may be updated when the application's actual features or data practices change. The effective date at the top of the page will be revised accordingly.

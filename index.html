Live Automation
for Sunday Palette.

A private, owner-operated tool that helps schedule and manage continuous music livestreams on the official Sunday Palette YouTube channel.

Personal use only · No public sign-up

Sunday Palette creates original soft pop, mellow jazz and nostalgic listening experiences. This companion tool supports the channel owner's livestream workflow; it is not a service offered to other YouTube creators.

What the application does

01 · Livestream scheduling

Reads the owner's live broadcast and stream status, then prepares upcoming livestream sessions using the YouTube Data API.

02 · Broadcast handoffs

Helps coordinate the transition between scheduled live sessions while preserving replay recordings of completed broadcasts.

03 · Owner authorization

Uses Google OAuth 2.0 so only the authorized channel owner can grant the permissions needed for broadcast management.

04 · Private operation

Runs on the owner's computers and private server. It does not provide public accounts, advertising services or third-party access to channel credentials.

Google API access and data use

The application requests YouTube management access through Google's OAuth consent process. It uses this permission for the owner's livestream and stream scheduling tasks. The permission is broader than simple read-only access; users should authorize only if they understand this access. See the Privacy Policy for details on data collection, storage, use, retention and revocation.
